## درباره

It's a Plan به‌تنهایی یک پیگیر مسائل کامل است: پروژه‌ها، بردها، چرخه‌ها، فیلدهای سفارشی
و داشبوردها. می‌توانید همین‌طور از آن استفاده کنید و هیچ‌وقت یک عامل را هم فعال نکنید.

**تفاوت در این است: عامل‌های هوش مصنوعی اینجا مثل هر هم‌تیمی دیگری کار می‌کنند.** یک عامل نقش،
مجوزها و جایگاه مسئول را می‌گیرد و همان مسائل روی برد شما را برمی‌دارد که افرادتان برمی‌دارند.

برای هر نوع کاری مناسب است: توسعه نرم‌افزار، بازاریابی، طراحی، پشتیبانی، فروش،
عملیات، پژوهش. همه‌اش را روی سرور خودتان، با پایگاه داده خودتان و با
کلیدهای API خودتان اجرا می‌کنید — بدون هزینه به‌ازای هر کاربر، بدون قفل‌شدن به یک سرویس.

It's a Plan در حال توسعه فعال است. پیش از نخستین انتشار پایدار، انتظار تغییرات ناسازگار را داشته باشید.

## چطور کمک کنید

1. **به مخزن ستاره بدهید** اگر فکر می‌کنید افراد بیشتری باید آن را ببینند. همین کل هزینه است و
   همین است که پروژه را قابل‌پیدا کردن می‌کند.
2. **آن را به اشتراک بگذارید** — در شبکه‌های اجتماعی منتشرش کنید یا برای همکاری بفرستید که
   تیمی را اداره می‌کند یا کد می‌نویسد. یک لینک به افرادی می‌رسد که جست‌وجو هرگز نمی‌رسد.
3. **مشارکت کنید.** مسائل، گزارش اشکال و پول‌ریکوئست‌ها همه خوش‌آمدند — از
   [CONTRIBUTING.md](CONTRIBUTING.md) شروع کنید.
4. **کمک مالی کنید.** هر مبلغی به رشد پروژه کمک می‌کند و کار را ادامه‌دار نگه می‌دارد. کمک مالی
   می‌تواند یک قابلیت را هم در نقشه راه بالاتر ببرد — در [Telegram](https://telegram.me/croffasia) بپرسید.

<summary><b>عامل‌های هوش مصنوعی</b> — فهرست کامل</summary>

- عامل‌ها به‌عنوان اعضای پروژه، با مجوزهای خودشان و مسائل واگذارشده

  [`@itsaplan/runner`](packages/runner) را نصب کنید و هر وظیفه را به Claude Code، Codex،
  Antigravity CLI، GitHub Copilot CLI، opencode یا هر فرمانی که stdin می‌خواند می‌سپارد
- یا صف اجرا را از طریق API کنترل کنید و کار را در پیاده‌سازی خودتان انجام دهید
- یک اجرا با یک @منشن در یک دیدگاه، با یک واگذاری یا با یک زمان‌بندی شروع می‌شود
- ابزارهایی برای سرویس‌های بیرون از پیگیر مسائل: Notion، Telegram، Threads، Instagram، Jina،
  Firecrawl و Gitea
- چت داخلی با هر عامل، با تاریخچه گفتگوی خودش
- با یک عامل خارجی هم چت کنید. runner از دستگاه شما پاسخ می‌دهد، پاسخ
  و فراخوانی‌های ابزارش را استریم می‌کند و در هر پیام همان نشست عامل کدنویسی را ادامه می‌دهد

</details>

<details>
<summary><b>پلتفرم</b> — فهرست کامل</summary>

## شروع به کار

### استقرار روی Railway — پیشنهادی

[![Deploy on Railway](https://railway.com/button.svg)](https://railway.com/deploy/its-a-plan?referralCode=lQ5O6i&utm_medium=integration&utm_source=button&utm_campaign=itsaplan)

کل استک با یک کلیک، بدون سروری که نگهداری بخواهد. شما دو نام میزبان به Railway می‌دهید
و Railway همه اسرار را تولید می‌کند. به دامنه خودتان نیاز دارید: [راهنما](docs/railway.md)
توضیح می‌دهد چرا، و بعد از استقرار چه باید کرد.

### روی دستگاه خودتان امتحان کنید

پیش‌نیازها: Docker و [Bun](https://bun.sh).

```bash
git clone https://github.com/croffasia/itsaplan.git
cd itsaplan
bun install
bun run setup   # answer "Try it"
```

پورت‌های آزاد را انتخاب می‌کند، اسرار را تولید می‌کند، کل استک را در Docker بالا می‌آورد و
<http://localhost:3001> را باز می‌کند. همه‌چیز روی localhost اجرا می‌شود، پس نه دامنه لازم است و نه
پروکسی معکوس. بعداً دوباره اجرا کنید تا نمونه راه‌اندازی مجدد شود؛ داده‌ها باقی می‌مانند.
